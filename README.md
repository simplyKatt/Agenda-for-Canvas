# Agenda for Canvas
---
A simple (and open-source) FF/Chrome extension that lets students see information about their assignments at a glance. 

>[!NOTE]
>While Agenda for Canvas works with the Canvas LMS, it is not made by, maintained by, or has any relation to Instructure Inc. Additionally, the usage of Canvas within the name "Agenda for Canvas" is under nominative fair use.
